# General Science Program (GSP)

The GSP program aims to empower elementary students by providing them with the tools and inspiration to explore their surrounding environment. Through engaging activities and STEAM-based hands-on projects, the program seeks to build their motivation for learning and expand their knowledge about career exploration.

## Landing Page

This repository contains a comprehensive landing page for the GSP program with 11 sections:

1. **Hero Section** - Program introduction with call-to-action
2. **About GSP** - Program overview and statistics
3. **Mission & Vision** - Core values and goals
4. **STEAM Activities** - Six types of hands-on activities
5. **Target Audience** - Information for elementary students
6. **Program Benefits** - Six key benefits of joining
7. **Success Stories** - Testimonials from students and parents
8. **Career Exploration** - Eight STEAM career paths
9. **How to Participate** - Three-step enrollment process
10. **FAQ** - Frequently asked questions
11. **Contact** - Contact form and information

### How to View

Simply open `index.html` in your web browser to view the landing page locally.
